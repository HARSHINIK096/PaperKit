02

Architecture & Data Handling

A. Zero User Accounts / Zero Personal Data

  • No Sign-Up or Login: There are no registration forms, sign-up flows, or user credential stores.
  • No Personal Data: We do not request or collect names, email addresses, phone numbers, or passwords.
  • No Advertising ID Trackers: We do not collect Advertising IDs (AAID), Android IDs, or hardware serials.

B. Anonymous Session IDs & Process Isolation

Why Anonymous User IDs Exist at Backend

Upon initial app launch, the client generates a local anonymous RFC4122 v4 UUID (StorageService.getAnonymousUserId()). This anonymous ID is sent in backend request headers solely for process isolation and concurrency protection—ensuring that if multiple devices invoke document processing endpoints simultaneously, each user's jobs, temporary storage, and rate limits remain strictly isolated without cross-user data collisions or file mismatches.

C. Files & Documents Processing

Client-Side Edge Engine

PDF merge, split, rotate, watermark, booklet, and WASM utilities execute 100% locally on your device. Files involved never leave your device.

15-Minute Server Purge

For cloud AI, OCR, or conversion tasks, uploaded files process in isolated server sandboxes and auto-purge permanently after 15 minutes.

Data Security & Encryption

  • TLS 1.3 / HTTPS Encryption: All data transmitted between the client app and backend servers is encrypted in transit.
  • AES-256-GCM Ephemeral Share Encryption: Temporary shared files are encrypted at rest with keys derived via PBKDF2-HMAC-SHA256.
07

Data Retention & User Control

Because no user accounts exist, there are no user accounts to delete. Users maintain full local control:

  • Reset Session Identity: Users can reset their anonymous session ID (StorageService.resetAnonymousIdentity()) at any time.
  • In-App Clear History: Open Settings (/profile) and tap "Clear Storage & History Data" to instantly purge local files and records.
